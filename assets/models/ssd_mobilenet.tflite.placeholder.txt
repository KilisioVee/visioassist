STEPS:
======

1. Download an SSD MobileNet TFLite model:
   - TensorFlow Hub: https://tfhub.dev/google/lite-model/object_detection/mobile_ssd/1
   - TensorFlow Lite: https://www.tensorflow.org/lite/guide/hosted_models
   - Or use any COCO-trained object detection TFLite model

2. Rename your model file to: ssd_mobilenet.tflite
   (Or update the path in lib/services/object_detection_service.dart)

3. Place it in this directory (assets/models/)

4. The model should be:
   - A .tflite file (TensorFlow Lite format)
   - Trained for object detection (not classification!)
   - Preferably quantized for faster inference
   - Around 30-100MB in size

EXAMPLE MODEL DOWNLOAD:
=======================

Using wget/curl:
  wget https://tfhub.dev/google/lite-model/object_detection/mobile_ssd/1?lite-format=tflite
  mv "1?lite-format=tflite" ssd_mobilenet.tflite

Or visit TensorFlow Lite's hosted models page and download the model manually.
