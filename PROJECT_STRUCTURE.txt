STATE MANAGEMENT
================

DetectionViewModel (Provider)
    ├─ detections: List<Detection>
    ├─ isLoading: bool
    ├─ isDetecting: bool
    ├─ errorMessage: String?
    ├─ confidenceThreshold: double
    └─ showLabels: bool

ObjectDetectionService (Singleton)
    ├─ _interpreter: TFLite
    ├─ _labels: List<String>
    ├─ _isModelLoaded: bool
    ├─ loadModel()
    ├─ detectOnImage(File)
    └─ detectOnFrame(CameraImage)

Detection Model
    ├─ label: String
    ├─ confidence: double
    └─ box: BoundingBox


INFERENCE PIPELINE
==================

[Camera Frame / Image File]
         ↓
[Resize to 300×300]
         ↓
[Normalize Pixel Values]
         ↓
[Convert to Tensor]
         ↓
[TFLite Interpreter.run()]
         ↓
[Parse Output Tensors]
  ├─ Bounding Boxes [1, N, 4]
  ├─ Class Indices [1, N]
  ├─ Scores [1, N]
  └─ Num Detections [1]
         ↓
[Apply Confidence Threshold]
         ↓
[Clamp Coordinates to [0,1]]
         ↓
[Create Detection Objects]
         ↓
[Return List<Detection>]
